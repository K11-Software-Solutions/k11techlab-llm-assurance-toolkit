Recommended remediation

Excessive Agency · LLM06:2025 Excessive Agency

Give tools the minimum permissions they need, require server-side authorization for every action, and put human approval in front of irreversible or high-value actions. The model should never be the only control between a user request and a side effect.

Improper Output Handling · LLM05:2025 Improper Output Handling

Treat model output as untrusted user input: HTML-escape before rendering, disable remote images in markdown or allowlist domains, use parameterized queries, and apply a Content Security Policy to chat UIs.

Prompt Injection · LLM01:2025 Prompt Injection

Keep system instructions separate from user and retrieved content; wrap untrusted content in clearly delimited blocks and tell the model to treat it as data. Add an input classifier for override attempts, constrain output format where possible, and never let model output alone authorize privileged actions.

Sensitive Information Disclosure · LLM02:2025 Sensitive Information Disclosure

Enforce authorization in the tools and retrieval layer, not in the prompt: the model should only ever see data the current user may access. Redact PII and secrets from retrieved context, add an output PII/secret scanner, and log and alert on hits.

Jailbreak & Policy Bypass · LLM01:2025 Prompt Injection (jailbreak)

Define an explicit content policy in the system prompt, add an output moderation layer, and red-team new prompt versions in CI before release. Refusals should be short and consistent; avoid persona prompts that can be hijacked.

Misinformation & Hallucination · LLM09:2025 Misinformation

Ground answers in retrieved, cited sources; instruct the model to say when it lacks information; add a groundedness check that compares claims to the retrieved context; and track hallucination rate as a release metric.

Scope & Topic Control · Business risk (brand, liability, cost)

State the assistant's scope and out-of-scope topics explicitly in the system prompt, give it a short standard redirect message, and add a topic classifier in front of the model for high-risk categories (medical, legal, financial advice).

System Prompt Leakage · LLM07:2025 System Prompt Leakage

Treat the system prompt as discoverable: never place secrets, credentials or internal URLs in it. Add an output filter that blocks the canary and long verbatim spans of the system prompt, and instruct the model to decline meta-questions about its configuration.
